4. Gestión de Módulos (ES Modules)
Un proyecto de backend no puede existir en un solo archivo. Node.js permite dividir el código en múltiples archivos llamados módulos. El estándar moderno de JavaScript es ES Modules (ESM).
Para habilitarlos, el archivo package.json debe contener la propiedad: type: module.
